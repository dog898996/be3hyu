# 호영 0.4.2 — 최종 코드 감사와 장기 사용 개선

[APK·전체 소스·검증 기록 다운로드](https://github.com/dog898996/be3hyu/releases/tag/v0.4.2) · [분야별 감사와 남은 한계](final-code-audit-v042.md)

여섯 분야의 코드 감사 후 통합 담당자가 변경분을 직접 다시 검토했다. 원문·기억을 지우지 않으면서 누적 기록으로 실행이 멈추는 경로, 진행 중 작업의 설정 충돌, 첨부·폰 알림·계정·응답 스트림 문제를 수정했다.

- 제외 기록 1,000개 안팎에서 기억 조회가 실패하던 SQL, 역사적 출처 분류, 권한이 없는 최신 기억 때문에 색인이 밀리던 문제 수정.
- 완료된 목표·옛 중지 기록이 현재 문맥을 채우던 문제와 과거 미해결 요청 증가로 새 작업이 막히던 문제 수정. 모든 원본 이력은 유지.
- 화면 이탈이나 별도 영구 설정 변경이 이미 맡긴 작업의 모델을 바꾸지 않도록 후속 처리까지 설정 보존. 해당 작업에서 명시적으로 변경하는 채팅 설정은 반영.
- 새 지시를 먼저 처리하면서 기존 Work 출력과 출처를 보존하고 이어서 재판단. 이전 폰 행동을 먼저 실행하거나 완료된 클라우드 행동을 자동 재전송하지 않음.
- 한도·미전송·불명확 결과 처리 후 주기 작업 점유와 임시 메모리를 정리. 실제 한도 소진은 계속 명시적으로 안내.
- 회전 중 첨부 수입, 동시 첨부 제거, 오래 열린 실행 한도·계정 편집, 종료된 화면 콜백을 수정.
- 알림 원문·보관 영수증의 사용자 제외 반영, 시작 시 활성 알림 확인, 실제 연락처 변경 행 수 확인.
- 계정 삭제 표식·외부 제어 동기화·백업 장벽 보완, 복구 코드 조회의 반복 이력 읽기 제거.
- 중단된 큰 응답 캡처의 스트림·슬롯 누적 해소. 공통 프롬프트 앞부분에서 변동 세션 정보를 분리.
