# 모델 선택과 첨부 전달: 검증 범위

모델 설정은 요구값이며 Work 화면에서 실제로 선택된 모델과 다를 수 있다. 기본값은 `gpt-6.1-sol / medium / fast`다. `gpt-6.2-sol` 같은 유효한 미래 이름도 지정할 수 있지만, 출시·계정 제공 여부를 확인한 것은 아니다. 모델 선택은 현재 Work UI에서 직접 해야 한다. 앱은 선택 증거를 검사하고 불일치를 차단하며 다른 모델로 자동 대체하지 않는다.

JS 검사 결과의 `requiredPreferences`는 요구값, `state.model/effort/speed`는 관찰값이다. 메뉴의 미선택 제공 목록이나 assistant 답변에 나온 이름은 관찰값의 증거가 아니다. 업로드를 기다리는 동안 실제 선택이 바뀌면 전송 전에 다시 검사하여 클릭하지 않는다. 선택을 되돌렸다고 불확실 요청을 자동으로 반복하지 않는다.

## 파일 경로와 한도

| 항목 | 폰 원본 | 실제 전송 | 이번 검증 |
| --- | --- | --- | --- |
| 사진 | 불변 원본·원본 SHA 보존, 최대 64 MiB | 예산에 맞으면 원본 그대로, 넘으면 별도 JPEG 표현 | 실제 JPEG File의 이름·MIME·바이트 일치 |
| 영상·음성 | 불변 원본 보존 | 원본 그대로, 개당 10 MiB 이하 | 영상·음성 이름/MIME를 가진 바이너리의 바이트·SHA 일치 |
| PDF·ZIP·기타 바이너리 | 불변 원본 보존 | 원본 그대로, 개당 10 MiB 이하 | 바이트·SHA·이름·MIME·순서 일치 |
| 빈 파일 | 원본 저장과 전송 지원은 별개 | 전송은 명시적으로 거부 | 혼합 요청도 전체 차단, 나머지 파일만 보내지 않음 |

한 요청은 최대 8개·전송 합계 20 MiB다. 큰 영상·음성·문서는 자동 축소하거나 자르지 않고 명시적으로 거부한다. 전송 공간을 확보할 때 문서의 정확한 원본 바이트를 먼저 예약하고, 사진에 남은 예산을 배분한다. 파일 입력이 형식을 허용하지 않거나 입력·업로드 준비 증거를 확인할 수 없으면 첨부 없는 텍스트로 대체하지 않는다.

native 전달표의 원본 `id/sha256/size`와 실제 전송 `wireName/wireMime/wireBytes/providerRepresentationSha256`를 구분한다. 축소 사진의 원본 SHA를 사본 SHA로 덮지 않는다. `originalBytesIncludedInWire`는 정확한 원본 전달 표현일 때만 true다. 준비표의 `originalBytesFullyUploaded`, `originalContentFullyInspected`, `serverBytesIndependentlyVerified`는 항상 false다. 실제 전달표도 모델 프롬프트에 포함하며 전체 입력 한도를 넘으면 자르지 않고 전송을 멈춘다.

## 확인한 것과 남은 것

Chromium DOM fixture는 파일 입력의 실제 `File`을 읽어 로컬 전송 바이트·SHA·크기·MIME·이름·순서와 composer 업로드 상태를 검사한다. 미디어 벡터는 전송 검사용 바이너리이며 영상·음성 코덱이나 문서 해석을 시험한 것이 아니다. 준비되지 않은 업로드, 지원하지 않는 `accept` 조건, 빈 파일, 업로드 중 모델 변경에서는 제출이 일어나지 않는지도 확인한다.

접수의 `uploadObserved/attachmentNames/uploadObservationScope`는 composer 표시의 관찰이다. 실제 서버가 바이트를 저장했거나 모델이 파일 내용을 읽었다는 독립 검증이 아니다. 이 검증에 실계정 인증·실제 Work 호출·유료 API 호출은 사용하지 않았다. 실제 Work DOM에 해당 파일 입력이 존재하고, 계정의 모델·첨부 처리 기능이 제공되는지는 아직 확인해야 한다.

실계정 검증은 정상 로그인 후 Work·임시채팅·요구 모델을 직접 선택하고, 작은 실제 파일을 형식별로 보낸 뒤 접수와 실제 처리 결과를 확인해야 한다. 큰 사진은 원본과 사본을 구분한 분석인지 확인한다. 서비스 한도나 입력 대기·인증 문제가 나오면 결과를 성공으로 기록하지 않는다. 실제 계정에서 제공하지 않는 형식까지 모든 파일을 처리한다고 약속하지 않는다.
