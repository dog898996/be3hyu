# 호영 0.4.13 — 마지막 실제 Android 검사에서 확인한 시작·연결 경쟁 수정

0.4.12의 설정 정리, 화면 복원, 첨부 중복, 파일 내보내기, 권한 복귀 수정에 더해 다음 세 원인을 수정했다. 기존 장기기억·전체 권한·서명은 유지한다.

- 시작 시 휴대폰 기록 읽기가 백그라운드 기록 정리 잠금을 기다리던 경로: 완성된 상태 파일을 원자 교체해 게시하는 성질을 이용해 읽기 잠금 대기를 제거했다. SHA-256 결과는 그대로 유지하며 바이트별 Formatter 비용을 없앴다. 실제 ANR은 CPU가 부족한 TCG 환경에서 관찰됐고, 앱 코드만이 전체 지연의 원인이라고 단정하지 않는다.
- 늦게 끝난 상태 읽기가 최신 쓰기나 백업 복원 후 캐시를 덮던 경쟁: 최신 캐시 승자를 보존하고 복원 후 캐시 세대를 교체했다. 수정 전 재현 실패와 수정 후 통과 로그를 남겼다.
- Work가 모델값을 확인한 직후, 선택창이 닫히기 전에 잠깐 연결 완료로 표시하던 경쟁: 실제 선택창·포커스가 해제될 때까지 전송 가능 상태를 공개하지 않는다. 합성 Android WebView의 지연된 전송 시나리오로 발견했다.

관련 시작·기록 JVM 검사 27개와 Work 브라우저 검사 25개가 통과했다. 앞선 관련 JVM 153개 통과 기록도 보존했다. 전체 장기기억 시뮬레이션이나 유료 모델 호출은 반복하지 않았다.

**전체 검증 통과판은 아니다.** 다섯 독립 KVM Android35 환경에서 각 28개씩 실행해 140회 중 105회 통과, 35회 실패했다. 모델 선택창 경쟁은 위 수정에 반영했으며 다섯 환경에서 Work 7개씩을 별도 재검사한다. 나머지 실패는 화면 회전 후 ActivityScenario 동기화, 실제 스크롤·버튼, SAF 테스트 공급자 선택, 알림 조작에 걸쳐 있다. 앱 결함과 검사 조작 결함의 구분이 끝나지 않은 항목을 통과로 처리하지 않는다. 실제 사용자 계정, 갤럭시 One UI, 장시간 운용의 성공을 보증하지 않는다.

사용자가 정한 1시간 마감에 맞춰 확인된 수정과 실패 증거를 모두 남긴 검증 후보로 제공한다. 최종 점수는 D 21, B 15, C 8, A 5, E 1이다. 5·10·15·20점 구간 종료 기록과 각 오류·수정 근거를 모두 보존했다.
