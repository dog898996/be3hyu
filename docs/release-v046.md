# 호영 0.4.6 — 모바일 모델 선택창 자동 처리

사용자 진단에서는 로그인·6.1 Sol·Medium은 확인됐지만 Fast는 미확인이었고, `composer_has_draft`와 이전 선택 오류가 함께 남아 있었다. 사진의 모바일 팝업은 기존 버튼·라디오 중심 구조와 달랐다. 이 경로에서 모델 선택창을 계속 열어두거나 수동으로 다시 고르도록 요구하지 않게 수정했다.

## 연결 동작

1. 닫힌 모델 버튼의 **화면에 표시된 값**을 읽는다. ‘추론 수준 선택’ 같은 접근성 이름은 현재 모델명으로 취급하지 않는다.
2. 값이 더 필요하면 앱이 알려진 모델 선택창을 연다. 모바일의 `pointerdown` 기반 열기와 일반 클릭 기반 열기를 구분해 이중 토글을 방지한다. 값이 아직 없다는 이유로 선택창을 여는 동작 자체를 막지 않는다.
3. 열린 창의 현재 모델 헤더·선택값·슬라이더의 안내와 위치·Fast 상태를 읽는다. 사용자가 이미 열어둔 창도 활용한다. 메뉴와 대화상자 형태를 지원하며, 주인 메시지나 일반 메뉴를 모델 설정으로 해석하지 않는다.
4. 앱 설정과 다를 때만 선택을 바꾼다. 슬라이더는 실제 표시된 위치 변화를 매 단계 확인하며 움직인다. UltraFast로 변경하거나 존재하지 않는 선택을 추정하지 않는다.
5. 확인을 마치면 선택창을 닫아 입력 포커스를 해제하고, 닫힌 버튼의 모델·강도와 같은 문서에서 확인한 속도를 함께 검증한다. 대기 메시지는 기존 큐를 통해 처리한다. 진행 중인 작업의 모델은 유지한다.

## 멈춤과 입력창 처리

- 설정 한 동작은 5초, 연속 자동 선택은 최대 25초의 확인 기한을 둔다. 모델 표시가 사라지거나 초안이 생겨도 기한 검사보다 먼저 빠져나가 계속 로딩하는 경로를 제거했다.
- 열기·관찰 실패는 **연결**로 다시 확인할 수 있다. 결과가 불명확한 Fast 토글·상대 슬라이더 이동은 무조건 다시 누르지 않는다.
- 선택 불가·모호한 선택·동작 횟수 제한도 네이티브에서 전송 전 준비 상태를 끝낸다. 원문을 보관하며, 이미 전송된 작업을 새로 실행하지 않는다.
- 숨겨진 안내 문구와 명시적인 편집기 placeholder 장식을 실제 초안으로 읽지 않는다. 실제 작성한 텍스트는 지우지 않고 그 상태를 표시한다.
- 진단에 선택창·슬라이더·Fast 제어 개수, 자동으로 연 여부와 초안 길이를 추가했다. 초안 본문·계정 토큰·전체 웹 DOM은 포함하지 않는다.

## 검사와 배포

브라우저 연결 검사 **77/77**, 네이티브 관련 검사 **4/4**, 서명 릴리스 빌드·필수 lint·APK 검사를 통과했다. 모바일 형태 재현에는 일반 접근성 이름과 별도 모델 표시, 슬라이더, 포인터로만 열리는 버튼, 아이콘형 Fast, 이미 열린 선택창, 자동 닫기 후 전송·응답 수집, 지연된 변경, 사라진 모델 표시, 실제 초안과 숨은 안내 문구를 포함한다. 기존 첨부·응답 수집·중복 전송 방지 경로도 연결 검사에 포함한다.

검사 기반은 사용자 사진·진단과 기존 고정 upstream의 모바일 power-picker 구조다. [upstream 모델 선택창 검사](https://github.com/miuuyy/codex-chatgpt-web/blob/0b6087c5307c7a58adda9c420358f3f70d2035f5/tests/chatgpt-model-family-browser.test.ts), [추론 선택창 검사](https://github.com/miuuyy/codex-chatgpt-web/blob/0b6087c5307c7a58adda9c420358f3f70d2035f5/tests/chatgpt-effort-browser.test.ts)를 참고했다. 고정 vendor 원본을 수정하거나 제공자 내부 API를 호출하지 않았다.

실제 사용자 휴대폰의 DOM·로그인 세션은 이 환경에 연결되어 있지 않다. 재현 검사와 APK 검사를 실제 휴대폰에서의 성공으로 보고하지 않는다. 유료 모델 호출과 전체 장기기억 시뮬레이션은 수행하지 않았다. 장기기억·설정·백업·권한 형식은 변경하지 않는다.

기존 앱 위에 업데이트하고 **Work → 연결**을 누른다. 모델 선택창을 직접 열어둘 필요가 없다.
