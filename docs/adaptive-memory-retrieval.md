# Bounded adaptive recall and source privacy

The ordinary `memory.search` path now preserves original source evidence before packing generated notes. When a user query contains an explicit relationship request or its initial lexical coverage is weak, it can follow an alias or relationship stated in an original owner message. This is a bounded search expansion: the source is not treated as a new instruction, and an alias is not promoted to a verified fact.

The expansion inspects at most six initial cue originals and makes at most three additional source queries, with at most twenty additional exact source-read attempts including failures. Each read requests up to 6,000 UTF-16 characters and validates the canonical record hash. A 350 ms operation-start budget stops additional work; a single SQL or original-integrity operation can take longer. Diagnostics expose attempted queries, source reads, source/hash paths, and incomplete coverage. Already-read originals are reconsidered when a newly discovered entity creates another edge, without reading them again. Rare query terms guide cue inspection; common-word frequency contributes only a small rank adjustment so independent semantic evidence can survive fusion.

Supported cues include explicit quoted aliases/relationships and ordinary Korean owner alias constructions such as `X을 Y라고도 부를게`. Negative or corrected relationship clauses are conservatively skipped. An unrelated negative sentence does not invalidate a separate positive cue. Only original owner messages drive this traversal. Assistant-generated guesses do not create owner relationships. Multiword followups can retrieve partial lexical matches, so all results remain labeled as search hints with exact source provenance.

Query expansion includes general registration, receipt, reference and identifier synonyms. Excerpt selection compares bounded candidate windows instead of stopping at the first repeated generic word. The formatter reserves source space first and distributes it across at most twenty original evidence items; generated summaries then use the remaining space. Every displayed original carries its record hash and source role, and excerpts do not imply whole-original inspection. Small budgets may omit sources; omission and retrieval limits remain explicit. Structured temporal validity still controls the interpretation of current versus historical notes.

Every search freezes the source privacy ledger before collection and verifies its fingerprint again before returning any model context. An unreadable or changed ledger blocks delivery. Exact, expanded, pinned, history, semantic-note and semantic-original lanes all apply the same scope. For derived notes, the filter streams all canonical dependencies, including citations beyond the displayed subset, and checks known asset/analysis metadata dependencies. A single excluded dependency blocks the note. Native answer lineage and supported parent-source links use `SourceRecordVisibility`; device observations retain permission checks. Replayed device observations are governed by the ledger's canonical-hash policy. No original payload is deleted by retrieval exclusion.

Aggregation requests explicitly report `completeRangeEnumerated=false` and require `paged_source_enumeration`. A top-ranked sample cannot substantiate an exhaustive sum, count, average or all-record answer. The separate native gateway/enumerator implements that operation and must carry its own coverage result.

## Verification

Fresh SDK35 Java compilation and host Robolectric SDK28 native SQLite execution passed **34/34 tests**, with no failures or skips: fourteen new adaptive/privacy tests plus twenty existing long-term retrieval regressions. The two-hop test uses random unseen entity names and proves its final original was absent from initial lexical candidates. It then checks exact source delivery, including the cached earlier cue. The unquoted alias regression covers a separate later negative sentence. Other cases cover rejected aliases, generated alias isolation, bounds, raw-source packing, registration synonym windows, exclusion of raw/pinned/mixed/history notes, all 140 canonical dependencies, semantic-device exclusion, policy changes during retrieval, corrupt-ledger failure, inherited assistant-source dependencies and aggregate incompleteness.

The existing semantic-only candidate regression is retained: adding a common lexical term cannot crowd out an independent semantic result. Its encoder, and the three-dimensional privacy encoder, are deterministic test seams. These tests measure native retrieval behavior and source/privacy contracts. They do **not** measure a trained model, years of actual user conversations, live provider behavior or a physical Galaxy phone. The separate longitudinal benchmark reports those synthetic scenario limits independently.

Machine-readable receipt: [adaptive-memory-retrieval-verification.json](adaptive-memory-retrieval-verification.json), with full JUnit output and exact source SHA-256 values. The normal Android unit suite can run the two named test classes; the recorded run used an isolated `javac`/JUnit harness so central Gradle ownership remained unchanged.
