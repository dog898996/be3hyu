# 호영 0.4.5 — 모바일 로그인 감지와 간결한 Work 연결

Work 화면에 모델이 보이는데도 `authentication_unverified`로 멈추던 경로를 보완했다. 기존 코드는 일부 프로필 버튼만 인식하고, 계정 확인이 안 되면 모델·Fast 확인도 진행하지 못했다. 모바일에서 프로필이 메뉴를 열 때만 생성되는 경우를 처리한다.

## 변경

- 최신 계정 버튼 식별자를 추가했다. 명확한 사이드바 열기 버튼이 있으면 한 번 열어 계정 표시를 확인하고, 앱이 연 메뉴만 닫는다. 모바일의 대화상자 형태 사이드바도 지원한다. Work 탭·모델·추천 카드만 보고 로그인을 추측하지 않는다.
- 관찰한 계정 표시는 같은 웹 문서에서 최대 5분만 기억한다. 메뉴를 닫아도 바로 미확인으로 되돌아가지 않으며, 만료되면 다음 연결 검사에서 다시 확인한다. 로그아웃·계정 전환은 이 확인을 무효화한다. 쿠키·인증 토큰·계정 이름을 추출하거나 저장하는 방식이 아니다.
- 빈 새 웹 대화에서는 Work를 선택하고 **앱에서 고른 모델·강도·Fast를 자동 적용**한다. 이미 맞는 모델은 바꾸지 않는다. 실제 화면 상태를 확인해야 연결 완료로 표시하며 UltraFast를 사용하지 않는다.
- 웹 초안·첨부·진행 중 응답이 있으면 연결 동작으로 덮어쓰지 않는다. 네이티브에서 전송한 작업은 읽기 전용 확인만 하며 진행 중 모델을 바꾸지 않는다. 연달아 연결을 눌러도 같은 메뉴 열기를 중복하지 않는다.
- 기본 화면은 두 줄 이내의 상태와 **연결** 버튼 하나다. 긴 설명과 가로 버튼 목록을 제거했다. **⋯**에 새 대화·상세·진단 복사·선택적 연결 테스트를 옮겼고, 삭제 복구는 필요한 기록이 있을 때만 표시한다.
- 장기기억·개인 설정·백업·폰 도구·권한과 0.4.4의 일반 Work 및 연속 지시 처리 방식은 변경하지 않는다.

## 사용

기존 앱 위에 업데이트하고 **Work → 연결**을 누른다. 로그인 입력이 필요하면 아래 ChatGPT 화면에서 로그인한다. 모델은 평소 앱의 선택 버튼이나 설정에서 정하면 된다. 평소 사용에 연결 동작 테스트는 필요 없다.

일반 Work는 활성 대화가 계정 기록에 표시될 수 있다. 세션 교체와 앱 기억의 기준은 [0.4.4 배포 문서](release-v044.md)를 따른다. 이 업데이트가 계정 메모리 기능 자체를 끄지는 않는다.

## 검증 범위

모바일 메뉴·로그인·Fast·초안·진행 중 요청에 대한 브라우저 fixture 12개, 네이티브 UI·작업 모델 보존 관련 4개를 집중 검사했다. 전체 장기기억 시뮬레이션은 반복하지 않았다. 유료 모델 호출이나 계정 설정 변경은 하지 않았다.

실제 사용자의 휴대폰 DOM, 실계정 로그인·전송은 이 환경에서 확인하지 못했다. 웹 구조가 fixture와 다르면 **⋯ → 연결 진단 복사**로 추가 확인이 필요하다. 로컬 검사 통과를 실계정 연결 성공으로 보고하지 않는다.
