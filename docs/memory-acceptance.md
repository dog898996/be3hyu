# 호영 장기 기억 수용 기준

원문을 잃지 않고 관련 증거를 정확하게 찾는 것을 별도 목표로 평가한다. 대화·폰 이벤트의 보관 기간에 따른 자동 만료를 두지 않으며, 모델 문맥 길이를 넘는 기록은 인덱스·기간·개체·출처별 검색과 원문 추가 읽기로 처리한다.

## 보관과 복구

이전 APK의 DB를 migration할 때 원문·기억 버전·작업 영수증을 보존한다. 출처가 없는 사실을 생성하지 않는다. 백업은 전체 기록을 한 객체로 메모리에 적재하지 않고 순차 처리하며 체크섬을 확인한다. 중단된 복원은 기존 정상 데이터나 새 데이터 중 일관된 상태로 회복한다. 복원한 미완료 작업은 자동 반복하지 않는다. 폰의 OS가 정보를 전달하지 못했거나 권한이 회수된 구간은 누락 구간으로 표시한다.

## 회상과 개인화

- 오래된 희귀 사실이 최근 무관한 10만~100만 건의 기록 때문에 후보에서 사라지지 않아야 한다.
- 같은 사실의 변경 전·후, 현재 상태와 과거 상태, 미확인 추론을 구분한다.
- 사람·프로젝트·장소의 별칭, 한국어 표현 차이, 날짜·기간과 출처 종류를 검색에 반영한다.
- 핵심 선호·계속 맡긴 책임을 일반적인 최근 작업 요약보다 우선 전달한다.
- 답변 근거의 원문 ID와 필요하면 원문 인접 문맥을 모델에 제공한다. 찾지 못한 사실을 기억한 것처럼 만들지 않는다.
- 자동 기억 검토는 처리한 원문 범위를 명시하며 결과를 저장하기 전에 처리 완료 cursor를 전진시키지 않는다.

## 평가

730일의 합성 대화·정정·알림·활동 데이터를 대상으로 희귀 사실 검색, 현재·과거 상태, 별칭, 관계 연결, 근거 없는 질문의 보류를 평가한다. 작은 기록과 큰 기록의 recall, 정확도, 검색 시간, 저장 크기를 비교하며 무관한 기록 증가에 따른 저하를 드러낸다. 실제 신경망 임베딩을 사용한 결과와 키워드·개념 확장 결과를 별도로 표시한다. 모델의 최종 답변 품질은 검색 코드 테스트와 분리한다.
