# 최종 5년 모의 기억 답변 검증

최신 V7 원문 검색과 별도의 실제 모델 답변 채점을 완료했다. 2021년 원문을 2026-12-31에 묻는 **서로 다른 144개 질문**에서 원문 방식과 같은 writer 기억을 사용한 방식 모두 144개를 통과했다. 정정·삭제·권한 철회·불확실성·사진의 실제 열람 여부·기간 범위까지 항목별로 채점했다. 이는 합성 기록의 검증이며 실제 5년 사용이나 실계정 Work·갤럭시 실행 인증이 아니다.

## 실제로 실행한 범위

- 2021-01-01부터 2026-12-31까지 2,191일, 잡음 기록 184,044건과 원래 출처 408개를 누적했다. 첫해 출처는 최종 시점에 모두 다섯 번째 달력상 기념일을 지났다.
- 같은 144개 질문을 세 체크포인트에서 실행한 432개 관측을 각각 보존했다. 432개를 독립 질문 수로 부풀리지 않는다.
- 최신 raw reader는 V7의 144개 실제 입력을 새로 읽고 답했다. 필요한 기간 질문에는 실제 native 열거 12회로 원본 168개를 확인했다. 주장 인용 364개를 각 입력 또는 자기 조회 응답과 대조했다.
- writer 방식은 독립 모델이 질문·정답 없이 원문에서 만든 기억 180개를 사용했다. V7에서 바뀐 입력 두 개는 실제로 다시 답하고 채점했다. 나머지 142개는 입력의 정확한 일치와 이전 실제 조회 23건의 V7 재실행을 검증한 뒤 기존 답변을 이어받았다. 새 writer 답변을 144회 실행했다고 표시하지 않는다.
- native 조회 재실행은 원본 179개의 내용·hash·날짜·범위가 일치했다. 열거 응답의 정책·범위 fingerprint는 제외 시각 차이로 달랐으며 그대로 보존하고 재계산했다. 이전 페이지 토큰은 재사용하지 않았다.
- 실제 원문 변경 한 조건과 관계없는 원문 변경 한 조건을 별도 복사본에서 실행했다. 독립 모델의 답변은 관련 변경에 따라 바뀌고 관계없는 변경에서는 같았다. 세 조건의 V7 입력이 이전 검증 입력과 정확히 같음을 확인했다. 한 사례의 검사이며 모든 추론의 증명이 아니다.

## 결과와 비교의 한계

| 항목 | 결과 |
|---|---|
| 최신 raw 실제 답변 | 144/144 통과 |
| 같은 writer의 V7 답변 | 144/144 통과, 142개 검증된 이월 + 2개 새 답변 |
| 동일 후속 조회 예산의 f2 기준선 | 144/144 통과 |
| 새로운 답변의 삭제·권한 철회 값 재노출 | 0건 |
| 최신 native 캐시·옛 백업 재생의 재노출 | 양쪽 0건 |
| 근거 없는 사진 직접 열람 주장 | 0건 |
| 월별 범위 질문 | 12개, 각각 실제 원본 14개 확인 |

동일한 모델 설정과 질문당 최대 검색 3회·원본 20개 조건에서 기준선도 100%였다. 따라서 **답변 정확도 비율은 1.0이며 오류 감소율은 정의되지 않는다. 답변 정확도가 2배 향상됐다고 입증하지 못했다.** RFC 원문이나 Dot의 경험적 정확도를 임의로 만들어 비교하지 않는다.

첫 입력에 필수 원문이 모두 들어오는 질문 수는 같은 writer 기준선 111/144에서 V7 132/144로 늘었다. 이 측정의 실패는 33건에서 12건으로 줄었다. 후속 조회 전에 필요한 원문을 제공하는 정도가 개선된 결과이며, 실제 답변 정확도 2배와 구분한다. 기준선에 있었던 native 문맥의 보호 값 노출도 최신 양쪽 평가에서는 없었다. 답변이 값을 말하지 않았다는 사실만으로 기준선의 문맥 노출을 지우지 않는다.

자동 writer는 전체 시계열 원문을 본 독립 추출 실행이다. 실제 앱에서 미래를 보지 않고 매일 자동 추출한 5년 실행을 검증한 것은 아니다. 합성 질문에는 반복되는 형식이 있으며 자유로운 한국어의 모든 표현에 같은 정확도를 보장하지 않는다.
