# 호영 0.4.12 — 설정·화면 복원·첨부·내보내기 호환성 수정

설정은 사용자 지침, 프로필, 모델과 속도, 실행 방식, 기억과 백업, 권한처럼 사용자가 실제로 결정할 항목 중심으로 정리했다. 불필요한 의미 검색 스위치와 비어 있는 작업 확인 카드를 제거했다. 의미 검색 기능과 기존 저장값은 유지한다. 앞선 0.4.11에서 제거한 백업 용량 `64` 입력칸, 사용량 절약 옵션, 반복 목표 입력칸은 다시 추가하지 않았다.

다섯 독립 검토자가 전체 앱을 자유롭게 살펴봤고, 이번 수정 과정에서 드러난 회귀를 포함해 다음 원인들을 재현했다.

| ID | 재현한 문제 | 수정 |
|---|---|---|
| F001 | 화면 재생성 시 선택 탭과 저장 전 설정·계정 입력이 사라짐 | 탭·입력·확장 상태·스크롤과 원래 충돌 비교 기준을 복원 |
| F002 | 같은 원본을 다시 첨부하면 중복 ID 때문에 전송 실패 | 불변 파일 ID를 합치고 기존 중복 초안도 원문·작성자를 유지하며 복구 |
| F003 | 비서 이름을 바꿔도 기본 플로팅 카드·녹음 알림에 이전 이름 표시 | 현재 이름 사용, 열린 기본 카드의 이름·사진도 갱신, 직접 지정한 카드 제목 유지 |
| F004 | 웹 답변의 숨겨진 코드나 공백이 실제 화면과 다른 명령 JSON에 포함됨 | 모든 원문이 렌더링될 때까지 기다린 뒤 정확한 코드만 수집 |
| F005 | 손상된 원본 내보내기 실패 전에 대상 기존 파일이 비워짐 | 원본의 존재·크기·해시·읽기 가능 여부를 먼저 확인한 뒤 대상 파일 열기 |
| F006 | 큰 계정 메모를 편집한 화면의 복원 상태가 1 MiB 초과 | 전체 미저장 내용은 비공개 임시 파일에 보존하고 Android에는 작은 참조만 전달 |
| F007 | 권한 안내를 완료해도 내부 탭이 ‘권한 설정’으로 남아 대화 갱신 누락 | 정상 대화 탭으로 돌아오도록 상태 정규화 |

F006의 임시 파일은 일반 기억이나 이식용 백업에 포함하지 않는다. 계정 삭제 시 해당 복사본도 정리하고, 백업 복원 전후 세대가 다른 편집 상태는 재사용하지 않는다. 파일이 없거나 손상되면 저장된 계정·설정을 덮어쓰지 않고 입력 복원 실패를 표시한다. 이미 실행 중인 작업의 모델을 화면 이탈 때문에 바꾸는 처리는 추가하지 않았다.

검증 결과와 환경별 한계는 [실험 기록](benchmarks/android-v0412-exploration-evidence/) 및 최종 검증 JSON에 구분해 남긴다. 실제 Android 계측은 로컬 합성 데이터와 오프라인 WebView를 사용하며, 사용자 계정 로그인·실제 Work 서버·갤럭시 장시간 실행을 검증한 것으로 설명하지 않는다. 장기기억 전체 시뮬레이션과 유료 모델 호출은 반복하지 않는다.

점수는 재현된 고유 원인에만 부여하며 같은 원인의 추가 사례는 새 오류로 세지 않는다. 사용자 요청에 따라 선두 점수 5·10·15·20점에서 최하위 탐색을 종료하고, 모든 발견 내용과 수정은 유지한다. 상세 점수와 종료 근거는 [기록](benchmarks/android-v0412-exploration-evidence/competition.json)에 있다.

현재 관련 JVM **153개**가 통과했다(152개 묶음 뒤 실제 계정 삭제 통합 검사 1개 추가, 크기 검사 1개 재실행). Chromium 전체 96개 통과 뒤 마지막 가드 변경에 관련한 8개를 다시 통과했다. 새 검사 추가 후 전체 97개를 반복 실행한 것은 아니다. 실제 로컬 Android35에서는 제품 검사 6개와 별도 오프라인 준비 검사 1개가 통과했다. 최초 시스템 UI 멈춤으로 실패한 설정 검사 4개도 기록에 남겼다. 다섯 환경 완주 및 실제 갤럭시·Work 계정 검증은 아직 완료되지 않았으므로 검증 후보로 배포한다.
