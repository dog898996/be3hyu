# 호영 0.4.0 배포 기록 · 검증 중

0.4.0은 대화 화면을 새로 정리하고, 휴대폰 권한을 실제 실행 도구·계정 기억·추가 인증에 연결한 버전이다. 앱 회원가입·사설 VM·상시 PC 없이 Android 앱에서 ChatGPT Work 임시채팅을 사용하고 원문·기억·작업 파일은 폰에 보관한다.

**현재 문서는 배포 전 초안이다.** 통합 unit suite·5년 원문 회귀·debug/release lint·서명 APK 정적 검증은 통과했다. 실제 API35 CI·공개 다운로드는 아래 표의 증거를 확인한 뒤 확정한다. 마지막 공개 설치 파일은 [0.3.2](https://github.com/dog898996/be3hyu/releases/tag/v0.3.2)이며, 새 UI가 포함된 0.4.0 배포 완료를 뜻하지 않는다.

## 변경된 동작

- **대화 중심 UI:** 사용자 제공 고양이 프로필, 좌우 말풍선, 날짜·시각, 첨부 입력창과 신규 메시지 등장 애니메이션. 입력 중 표시에는 실제 사용자 답변 상태를 사용하고 숨김·종료·절전 애니메이션 설정을 반영한다. 대화·Work·기억·계정·파일·권한·설정은 사이드바에서 연다. [11개 화면과 동작](ui-redesign.md).
- **기억에 남는 이모지 응답:** AI가 가벼운 근황에 문장 대신 반응할 수 있다. 대상 ID·원문 hash를 확인하고 assistant 원문과 근거 영수증으로 저장해 답변·읽음·기억·백업·제외·삭제에서 정식 응답으로 처리한다. 중요한 질문·요청·정정은 문장 답변을 사용한다.
- **정확한 계정 보관함:** 서비스·아이디·비밀번호·메모의 최신 값, 정정 이력과 출처를 보관한다. 인증앱 비밀키·복구 코드·추가 인증 메모를 직접 편집하고 알 수 없는 추가 JSON 값은 보존한다. 전용 계정 복사본 삭제와 일반 대화 원문 삭제를 구분한다. [로그인·MFA와 백업 범위](account-login-status.md).
- **실제 추가 인증 도구:** RFC6238 TOTP를 입력 직전에 계산하고 만료 시각을 확인한다. 복구 코드는 반환 전에 영구 예약하며 옛 ZIP 복원 뒤에도 예약·공개 이력을 합친다. 외부 폴더 오류로 미공개인 예약은 대화가 끝난 뒤 새 요청에서도 검증된 참조로 재개하며, 공개를 확정한 코드를 옛 대기 기록으로 자동 재공개하지 않는다. 비밀번호·코드 입력 접수와 서비스 인증 성공은 별도로 확인한다.
- **권한과 휴대폰 기능 연결:** 48개 manifest 선언과 특수 접근을 실제 OS 상태로 검사한다. 지원되는 필수 권한이 빠지면 시작 화면에서 대화를 막고, SMS·통화 기록은 설치 프로그램 허용 조건과 실제 grant를 따로 표시한다. 알림 동작·답장, 연락처·일정, 화면 입력·캡처, 파일·미디어 전송, 녹음, 예약 알림, Bluetooth·Wi-Fi 등의 실제 실행 경로를 연결했다. [권한별 기능·검증 수준](permission-capability-matrix.md).
- **사용자가 정하는 실행 정책:** 실행기의 전체 도구 목록으로 권한 스위치를 구성한다. 기능은 기본 허용이고 도구 실행 턴·한 턴의 행동 개수는 기본 0, 즉 앱 개수 제한 없음이다. 잠금 화면 답장 내용·알림 제안 동작·Work 다운로드와 실행 한도는 권한 화면이나 대화로 변경한다. [정책 변경 기록](app-permission-policy-audit.md).
- **실제 결과를 따르는 완료 처리:** 새 사용자 지시·명시적 중지·현재 권한과 원문 제외를 다시 확인한다. 녹음·화면 캡처·예약·문자 등 비동기 요청은 실제 callback 영수증으로 후속 상태를 확인하며 결과를 모르는 동작을 자동 반복하지 않는다. 에이전트가 자기 입력창을 조작한 내용은 사용자 발언으로 위장하지 않는다.

## 장기 기억과 사용량

원문·정정·삭제·제외·검토 ACK·출처·검색 예산을 유지했다. 계정 원문은 일반 대화의 기억 문맥에 비밀번호 전체를 고정하지 않고, 명시적인 계정 조회와 기존 원문 경로로 읽는다. 전체 기억 ZIP에는 계정 원문과 추가 인증 정보도 포함한다. 삭제·제외 정책과 복구 코드 예약은 외부 보존 폴더에도 기록하며, 재설치 후 **같은 폴더를 먼저 다시 연결한 뒤 전체 ZIP을 복원**한다. 전체 대화·첨부 ZIP의 자동 주기 백업을 구현한 것으로 설명하지 않는다.

[최종 5년 원문 회귀](benchmarks/android-v040-five-year-memory-regression.json)는 합성 2,191일과 방해 기록184,044건에서 **432/432개 출처 조건**을 통과했다. 최종 **144/144개 전체 기억 패킷**은 0.3.2와 바이트 단위로 동일하다. 삭제6건, 옛 캐시12건 거절과 옛 백업 복원12개 조회도 통과했으며 보호 원문 누출은0건이다. 실제 native SQLite와 동결한 기억·저장 소스를 사용했다. AccountTools·AccountMfaTools 실행 facade는 이 원문 fixture에서 제외했고 계정·MFA는 별도 테스트로 확인한다. 새 모델144개 답변 채점이나 실제5년 사용 결과가 아니다.

사용자 답변은 Fast, 기억 검토는 Medium 이상을 유지한다. 정기 판단의 Light→Medium→High 분리와 실제 공급자 한도 소진 처리는 유지하며 일평균10% 목표 때문에 대화·자율 판단·기억을 강제 중단하지 않는다. 늘어난 도구 명세가 필수 원문 문맥을 밀어내면 이름별 정확한 명세 조회를 사용한다. 실제 하루10%나 답변 지연·성능 동등성을 측정한 결과는 아니다. [사용량 설계와 관측](token-optimization.md).

실제 Galaxy S24 Ultra 장기 운용·배터리, 실계정 Work의 모델·파일·코드 도구, Instagram 등의 로그인과 MFA·CAPTCHA·FIDO, 실제 통화·문자 전달은 이 합성 시험의 검증 범위에 포함되지 않는다. 입력·Android 요청 접수·callback 완료·외부 서비스의 성공을 각각 구분한다. Fast 선택은 즉답 보장이 아니며 OS 강제 종료·전원 꺼짐·네트워크 단절에서24시간 연속 실행을 보장하지 않는다.

개발·검증에 추가 유료 API·사설 VM·유료 CI를 사용하지 않았다. 기존 ChatGPT 구독의 실제 사용 가능 여부와 한도는 별도다. 실제 비밀번호·쿠키·사용자 DB·서명 개인키는 공개 소스나 배포 파일에 넣지 않는다.
