# Completed indexed V5: recall evidence and latency improve

The latest frozen production Store/Retriever/Gateway completed the unchanged six-year workload and all **432 checkpoint cases per arm**. Raw final source delivery was **144/144 cases and 396/396 exact originals**. With the identical independent writer notes it was **132/144 cases and 383/396 originals (96.72%)**. Both recovered **12/12 rare first-year raw details** after five-plus calendar years of synthetic accumulation, with zero candidate/context leaks and zero blocked cases. **Independent final model answers are still unmeasured in this report**, so the user's final answer-quality gate remains open.

| Matched preprocessing | Frozen f2 final cases | V5 final cases | Required originals in V5 | Complete-source error ratio |
|---|---:|---:|---:|---:|
| Raw originals | 130/144 | 144/144 | 396/396 | 0.000 |
| Same writer notes | 111/144 | 132/144 | 383/396 | 0.364 |

Those error ratios meet the registered halving target **for complete source delivery**, not for grounded answers or the uploaded RFC as a whole. Paired raw transitions are fourteen fail-to-pass and zero pass-to-fail. Writer transitions are thirty-two fail-to-pass and **eleven pass-to-fail**. The remaining writer gaps are eleven current temporal original texts plus two original bodies in one fourteen-record range. Current temporal values remain visible in verified derived notes; that does not establish that a reader will answer them correctly. Real source reads and date/literal enumeration can supply additional evidence, within the registered three-search/twenty-row limits.

The source candidate ranking and final delivery are different measurements. Native Retriever source recall@5/@12 was 237/396 and 334/396 in raw, and 166/396 and 173/396 in writer. The Gateway's independently ranked, canonically hydrated source lane recovers additional originals before packing. These numbers must not be described as neural recall: this standalone run has no semantic encoder and uses the actual lexical production fallback.

Measured native preparation is much faster than the previous complete V4 phase:

| Arm | V4 final p50/p95 | V5 final p50/p95 |
|---|---:|---:|
| Raw | 5,818 / 13,103 ms | 362 / 850 ms |
| Writer | 5,851 / 12,974 ms | 411 / 1,081 ms |

These shared-host timings exclude model reasoning, Work calls and phone execution. The indexed candidate/specificity ranking replaces the observed full-table computed LIKE/order scan, preserves canonical source/hash verification and scope checks, and compacts originals while retaining recording date and completion. Exact source manifests distinguish every phase. Timing ratios are descriptive; concurrent host loads were not controlled experimental replicates.

Managed-local privacy checks passed in both V5 arms: all twelve actual cached first-year scopes previously containing protected values were rejected after policy changed; the actual year-one backup could not roll back current policy; six restored message deletions re-purged successfully with zero pending jobs; and all twelve restored queries completed without protected-value exposure or blocking. Already delivered bytes, RAM, provider archives, external/untracked copies and policy after reinstall/data clear remain outside this verified scope.
