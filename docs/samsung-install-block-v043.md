# Galaxy 설치 차단 분석 — 0.4.3

확인일: 2026-10-14. 기기: 사용자가 보고한 Galaxy S24 Ultra. 이번 작업은 설치 차단 분석과 안내 수정이며, 앱 기능·권한·패키지·서명·APK는 변경하지 않았다.

## 사용자 화면과 판정 범위

사용자 스크린샷에는 **‘악성 앱으로 의심’**, ‘악성으로 신고되었거나 그와 유사’, **‘이 제한은 끌 수 없습니다’**와 확인 버튼만 표시된다. 사용자는 출처 불명 설치를 허용했고, 앞서 ADB로 설치했다고 보고했다.

이는 일반적인 ‘자동 차단 기능으로 설치 차단’이나 설치 후 접근성·알림 접근의 ‘제한된 설정’과 구분해야 한다. 화면 문구만으로 이 앱이 실제 신고되었는지, 유사성 판단인지, 어느 검사 엔진이 어떤 조건으로 차단했는지는 알 수 없다. ADB 설치 성공도 일반 설치 프로그램의 판정 해제나 보안 검사 승인을 뜻하지 않는다.

삼성 Community Manager는 자체 제작 앱의 유사 사례에서 유관부서 확인 후 보이스피싱 방지를 위한 설치 제한과 별도 APK 검토 절차를 안내했다. 이는 이번 화면을 해석할 근거지만, 호영 APK에 대한 삼성의 개별 판정서는 아니다.

## 현재 배포 파일에서 확인한 사실

검사 대상은 저장소에서 배포한 0.4.3 APK다. 사용자의 폰에서 차단된 파일의 버전·SHA-256은 아직 대조하지 못했다.

## 가능한 원인과 한계

호영은 SMS 읽기·수신, 알림 접근, 접근성 기반 화면 읽기·조작을 실제 기능에 사용한다. Google은 일부 시장에서 인터넷을 통해 설치하는 앱이 이들 민감 권한을 선언하면 사기 방지 정책에 따라 설치를 차단할 수 있다고 명시한다. 따라서 **설치 경로와 권한 조합은 검토할 원인**이다.

Google 문서의 조건이 이번 삼성 화면의 직접 원인이라는 증거는 아직 없다. 정확한 One UI·Android 버전, 실제 차단 APK, 설치 시 시스템 진단 정보 또는 제조사 답변이 필요하다. 과거 삼성 담당자 답변도 현재 모든 기기·개인용 앱에 대한 승인 보장은 아니다.

검사한 배포본에서는 잘못된 서명·손상된 ZIP처럼 기능을 유지한 채 고칠 수 있는 설치 파일 오류를 발견하지 못했다. 단순 이름·아이콘·해시 변경이나 재서명을 원인 해결로 제시하지 않는다. 현재 근거만으로 ‘코드 수정으로 일반 설치가 가능해졌다’고 보고할 수 없다.

## 기능을 유지하는 검토 경로

1. One UI·Android 버전, 설치 시각·설치 앱, 실제 APK 버전과 지문을 확인해 검사 대상을 일치시킨다.
2. 삼성에 이 화면의 판정 사유와 **개인용 자체 개발 앱**의 검토 가능 여부를 문의한다. 공식 담당자 안내의 기업 앱 예외 등록을 개인 앱에도 자동 적용된다고 해석하지 않는다.
3. 삼성 담당자의 공개 안내는 기업 앱 또는 스토어 등록 앱의 APK 검토 경로를 제공한다. APK는 링크 대신 파일 첨부를 요청한다. 현재 APK는 약 79 MB이므로 개인 앱 접수 가능 여부와 대용량 파일 전달 방법도 확인해야 한다.
4. Google Play Protect 판정이 별도로 확인된다면 Google의 공식 이의 신청 경로를 사용한다. 두 검토 절차를 같은 것으로 취급하지 않는다.

외부 검토 신청이나 APK 전송은 수행하지 않았다. 기기에서의 일반 설치 성공, 예외 승인, 추후 업데이트 시 차단 해제는 모두 미확인이다.
