# 호영 0.4.3 — 모델 선택과 Work 연결 진단

[APK·전체 소스·검증 기록](https://github.com/dog898996/be3hyu/releases/tag/v0.4.3)

- 보내기 옆과 영구 설정의 모델 직접 입력란을 제거하고 **6 Sol / 6.1 Sol / Astra** 선택으로 변경.
- 두 곳에 **Fast 스위치** 추가. 끄면 Standard이며 절약 설정이 다시 Fast로 바꾸지 않는다. UltraFast는 사용하지 않는다.
- 임시 속도 선택은 화면을 벗어날 때 다음 새 메시지에 대해서만 초기화된다. 이미 맡긴 작업·후속 호출은 선택한 모델·강도·속도를 유지한다. 채팅에서 speed 변경과 강도만 추가 변경하는 경우도 확인했다. 영구 속도는 기존 설정 백업에 포함된다.
- Work의 `GPT-6.1 Sol Medium`처럼 합쳐진 표시, 모바일 사이드바에 접혀 있는 계정 표시, 연결된 모델 메뉴의 Fast 스위치 감지를 보완했다. 메뉴를 닫아도 그 문서에서 확인한 속도를 보존하고, 메뉴를 다시 열거나 모델·강도 증거가 바뀌면 재확인한다. 메뉴를 열었지만 확인된 속도가 없으면 추정하지 않는다.
- 세부 오류를 모두 ‘Work 연결 확인 필요’로 덮어쓰던 UI를 수정했다. 로그인·Work·임시 채팅·모델·강도·속도를 보여 주고, **연결 진단 복사**를 Work 탭에서도 제공한다. Work 선택 실패 이유와 최상위 페이지 로딩 오류를 유지한다.
- 연결 전 ‘검증 요청’은 추가 모델 요청을 쌓지 않고 연결 단계부터 안내한다. 실제 접수가 확인되기 전에는 읽음으로 표시하지 않는다.

변경 관련 Android **71/71**, 브라우저 fixture **13/13** 통과. [검사 기록](benchmarks/android-v043-focused.json). 전체 장기기억 시뮬레이션·유료 모델 호출은 반복하지 않았다.

사용자가 보낸 화면에서 Work와 합쳐진 모델 표시를 확인했다. 실제 기기의 DOM·로그인 세션에 직접 접속한 검증은 아니므로 **실계정 연결 성공은 아직 미확인**이다. 계정별로 다른 모델 메뉴·추론 슬라이더 등 미지원 구조는 진단 안내가 필요할 수 있다. URL만으로 임시 채팅 성공이나 모델 실행 성공을 간주하지 않는다.

업데이트 후 Work에서 **새 임시 대화 → 웹의 Work·임시 채팅 확인 → 연결 확인** 순서로 확인한다. 진행 중인 기존 작업이 있다면 먼저 그 결과를 확인한다. 막히면 같은 탭의 구체적인 상태와 연결 진단으로 이어서 확인할 수 있다.
