# 호영 0.4.1 — 화면 모델 선택과 편집 가능한 프로필

**화면을 떠나면 다음 메시지의 임시 선택만 초기화하고, 이미 맡긴 작업은 처음 선택한 모델·강도를 후속 처리에서도 유지한다.** 진행 중 Work에 모델 변경·취소를 보내지 않는다.

[APK·전체 소스·검증 기록 다운로드](https://github.com/dog898996/be3hyu/releases/tag/v0.4.1) · [설정 동작과 백업 범위](routing-and-identity-v041.md)

- 보내기 옆에서 이번 화면의 모델·추론 강도를 선택한다. 여러 메시지와 앱 내 탭 이동, 회전에도 유지된다. 홈·다른 앱·화면 꺼짐·프로세스 종료 뒤의 새 메시지는 영구 설정을 따른다.
- 채팅의 임시 변경은 같은 기능을 사용한다. 영구 변경은 설정 화면 또는 채팅에서 가능하다. 오래 열어 둔 화면이나 늦게 도착한 변경이 더 최근 설정을 덮어쓰지 않는다.
- 정기 판단은 기본 Medium·Standard로 이행한다. 사용자 응답·지시 후속 처리는 Fast를 유지한다. UltraFast는 사용하지 않는다.
- 기본 이름 호영과 고양이 사진을 설정·채팅에서 바꿀 수 있다. 현재 이름·프사는 UI·프롬프트에 반영하고 과거 이름을 현재 정체성으로 사용하지 않도록 한다. 새 프사는 실제 첨부 경로로 확인하고 관찰 영수증이 있는 설명만 보관한다.
- 프로필, 사용자 지침, 모델·추론·속도, 기억·자율·권한·알림·실행 옵션과 사진 원본을 전체 ZIP에 함께 보관한다. 화면 임시 선택은 복원하지 않는다. Android 권한·외부 폴더 승인과 WebView 로그인 세션은 별도다.
- 설정을 프로필, 기본 모델, 정기 판단·기억 모델, 사용자 지침, 자율 실행, 기억·백업, 사용량, 진단으로 정리했다.

검사는 실제 SQLite·네이티브 Java UI 수명주기와 모의 Work 전송을 사용했다. 이번 변경에서 실제 Galaxy S24 Ultra, 실제 Work 모델 출력·계정 로그인, 24시간 연속 운용을 측정한 것은 아니다. 전체 5년 시뮬레이션과 전체 에뮬레이터 검사는 사용자의 요청대로 반복하지 않았다. 기억 검색·정정·삭제 알고리즘은 변경하지 않았다. [0.4.0 전체 검증 이력](release-v040.md)은 이 버전의 새 실기기 검사로 합산하지 않는다.

프로세스가 강제 종료돼도 저장된 모델 선택은 보존된다. 기존 Work 접수 결과를 모르는 경우에는 기존 복구 규칙을 따르며, 같은 클라우드 행동을 무조건 다시 실행하는 것으로 설명하지 않는다. 원격 작업이 끊김 없이 복구된다는 보장과 앱 내부의 선택 보존은 구분한다.
