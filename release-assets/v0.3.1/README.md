# 호영 0.3.1 배포 파일

검증 코드 `1606ca6871056b223a749ec2c5d01218ae71e58c`, 최종 문서 포함 소스 `232dbad28e51106e964c458c53a8b69be40d9177`. 같은 검증 입력 191개 파일을 대조했다. 안정 서명 versionCode5, 권한40개를 유지한다.

전체 기억 ZIP은 수동 저장이며 작은 삭제·제외 정책만 선택한 공유 폴더에 자동 보존한다. 재설치 후 같은 폴더를 먼저 연결하고 ZIP을 복원한다. 실제 OS 제거·재설치, Galaxy picker/응답속도, 실계정 Work 작업은 미측정이다.

업로드 호스트 인증 거부로 검증 파일을 별도 Git 브랜치에 보존하고 Release는 고정 커밋 다운로드를 연결한다. 설치 개인키와 실사용 데이터는 포함하지 않는다.
